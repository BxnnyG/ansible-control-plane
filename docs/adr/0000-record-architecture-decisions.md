# ADR-0000: Record architecture decisions

- Status: accepted
- Date: 2026-11-03

## Context
Decisions must survive chat sessions and be reviewable in a public repository.

## Decision
Every stack or architecture decision is recorded as a numbered ADR in `docs/adr/` (Context, Decision, Consequences, Alternatives). Deviations from `PLAN.md` §9 require a new ADR. Superseded ADRs stay and are marked as such.

## Consequences
Small overhead per decision; reliable project memory.
